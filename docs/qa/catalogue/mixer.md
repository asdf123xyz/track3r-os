# Mixer: feature catalogue

One row per user-visible function of the Mixer screen (`docs/ui/ui-map.md` section 1; fixed table of `docs/specs/OS-FINALQA.md` section 1). IDs are never reused. The simulator scenario is `sim/scenarios/qa/qa_mixer.txt`, its goldens are the `qa_mixer/qa_mix_NNN` keys of `sim/goldens.txt`. These rows come from OS-UIFIX (UI only: no unit step); the Shift row is Global's jumps over the rows. The rest of the screen's rows are added by the final batch.
