# OS-QANET part E: triage of the differences

From `expectations.md` (194 expectations of an owner of the official firmware, written with no project documents and no official manual) and `differences-1.md` / `differences-2.md` (each compared with the QA catalogue and the code; a static read, nothing was run). Every row is an open research question until the maintainer decides it. Rule (maintainer, 2026-10-21): a finding blocks `rc/1.0.0` unless the maintainer marks it "after 1.0".

Fill the last column with one of: `before 1.0`, `after 1.0`, `not a bug` (the OS is right), `idea` (an IDEA row), or a note. The recommendation follows the severity; it is not a decision.
