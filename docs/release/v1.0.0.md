# track3r-os v1.0.0: release notes

## What this is

track3r-os is community firmware for the Polyend Tracker. It is unofficial and not affiliated with Polyend. Installing it replaces the firmware in your unit. It is licensed GPL-3.0-or-later. Third-party licences are in [THIRD_PARTY.md](../../THIRD_PARTY.md).

**Back up your SD card and keep the official firmware file before you install.**

## Files

- `track3r-os-v1.0.0.ptf`, the update file. Do not rename it.
- `SHA256SUMS`, the checksum of the `.ptf`.

SHA-256 of the `.ptf`: 379bad017e1829c23040b2387e5e100cf4324c7ce6bcf9126161f90876336986

Check your download with `sha256sum -c SHA256SUMS`.

The app modules are a separate download: the release `apps-v1.0.0` ("track3r-os v1.0.0 apps") on the Releases page. Unpack its zip into the card root.

## Install

1. Copy everything on the SD card to your computer.
2. Copy `track3r-os-v1.0.0.ptf` into `Firmware/` on the card. Make it the only `.ptf` there.
3. Put the card in the unit and use the hidden reset button, as in Polyend's [emergency flashing page](https://polyend.ladesk.com/929798-How-do-I-perform-the-emergency-flashing-procedure).
4. After the restart, open Config, INFO. BUILD ID should show `v1.0.0`.

The official update menu does not list this file. A unit that already runs track3r-os can also update from its own Config, INFO page (`F8`). The full steps and risks are in the [installing guide](../manual/install.md).

## Going back to the official firmware

1. Move every `.ptf` out of `Firmware/` on the card.
2. Copy the official `PolyendTracker_<version>.ptf` into `Firmware/`, as the only `.ptf`.
3. Flash it with the hidden reset button, as above.

The bootloader is separate, so a broken track3r-os does not remove the way back. Details are in the [installing guide](../manual/install.md).

## Highlights

The full list is in the [changelog](../CHANGELOG.md).

- Perform: PLAYBACK plays the next notes backward.
- Perform: SMP POS and SMP END set where notes start and stop in a sample.
- Perform: VOL, PAN, TUNE, FLT and POS LFO rows change the LFO speed.
- Perform: each track can have its own next pattern.
- DJ page: smoother scratch, TAPE STOP with a length, finer crossfader pads.
- Sample edit: FILTER and COMPRESSOR, and `F8` cancels a running effect.
- Sample load: several files at once, with the target instrument on screen.
- Record: START ON LEVEL with THRESHOLD and PRE-ROLL, and TIME LEFT.
- Update from the unit: Config, INFO, `F8` installs a `.ptf` from the card.
- The audio clock is exactly 44,100 Hz.

## Known issues

- Swapping the SD card can crash the unit. It was seen once with a project of samples loaded. Switch the unit off before you change the card.
- Very heavy projects can exceed the CPU budget. A 12-track test project ran at 113 % mean CPU and sound dropped out. The keys still answer and Stop works. See the [CPU budget](../architecture/cpu-budget.md).
- Some Perform effects cost CPU while held. On a project near the budget, holding PLAYBACK or the LFO rows on many tracks can make the sound drop out. Release the pad.
- The update list on the unit shows only the first 12 files of `Firmware/`. Keep 12 or fewer files there.
