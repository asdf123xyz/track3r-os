# Pad 3 in the Instr column only previews (Browse, the default mode; OS-PADHOLD: it no longer chooses the instrument);

press shift

# Instr -> Vol -> FX1 with two presses to the right, then Fx toggles FX1 -> FX2.

# 40 -> 35; Left from FX2 is FX1, then the Note button jumps to the Note column.

# OS-QJUMP: Shift + Note, Instr, Vol (FX1) and Fx (FX2) jump to 0, 1/4, 2/4 and 3/4 of the pattern (rows 0, 16, 32, 48 of the demo's 64 steps); the column stays.
