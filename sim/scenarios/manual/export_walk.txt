# (manifest: docs/manual/images.txt; tools/manual_images.py renders it, ctest o3sim_manual_images keeps the committed pictures in step). A new step or a changed key means a changed picture: edit the

# Step 1. Press `File`. The File screen opens on the PROJECTS page.
tap file
wait 20
assert state screen=FILE

# Step 2. Press `F7` (EXPORT). The EXPORT page opens with the cursor on SONG.
tap f7
wait 20
snap walk_2

# Step 3. Press `Down`. The cursor is on PATTERN nn; the WHAT line says "the pattern once, with its tail" and the FORMAT line says 16-bit stereo, 44,100 Hz. (The demo has one pattern, so the encoder has nothing to change here.)
tap down
wait 20
snap walk_3
